ctags-lang-lisp¶

Random notes about tagging Lisp source code with Universal Ctags

Version:

6.2.0

Manual group:

Universal Ctags

Manual section:

7

SYNOPSIS¶

ctags … --languages=+Lisp …
ctags … --language-force=Lisp …
ctags … --map-Lisp=+.cl …
ctags … --map-Lisp=+.clisp …
ctags … --map-Lisp=+.l …
ctags … --map-Lisp=+.lisp …
ctags … --map-Lisp=+.lsp …
